# UK SED — support and privacy

The support and privacy page for **UK SED**, an iOS app that tracks qualifying
days for the UK Seafarers' Earnings Deduction.

Published at <https://lucngd.github.io/uk-sed/>. The App Store listing points
its Support URL and its Privacy Policy URL here.

`index.html` is deliberately self-contained: no fonts, scripts, analytics or
stylesheets are fetched from anywhere, so a page that claims to collect nothing
also leaks nothing. The policy text is kept in step with `AppStore/PRIVACY.md`
in the app's own repository, which is where it is written.

This repository holds the page only. The app source is not here.
